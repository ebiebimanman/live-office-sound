設定

音を流す枠の数 ／ 自動登録まで 分
検索ワード（1行に1つ）
必須ワード（どれか1つをタイトルか説明文に含む配信だけ流す。作業配信らしさの判定用。空にすると無効）
除外ワード（1行に1つ。タイトル・チャンネル名・説明文に含まれていたら流さない）
例外ワード（これを含む部分は除外判定に使わない。例：「BGMなし」の「BGM」で除外されないように）
URLを直接再生（1枠目に読み込み）
★ 登録チャンネル
✕ 除外チャンネル
APIキーの取り方（最初に1回だけ）
  1. Google Cloud Console で新しいプロジェクトを作る（名前は何でもOK）
  2. 「APIとサービス」→「ライブラリ」で YouTube Data API v3 を検索し「有効にする」
  3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」
  4. 作成したキーの編集画面で制限をかける
    • アプリケーションの制限：ウェブサイト → を追加
    • APIの制限：YouTube Data API v3 のみ
  5. キーを上の「設定」に貼って「保存して反映」
無料枠は1日10,000ユニット。候補の検索1回で約600〜1,100ユニット使い、結果は30分キャッシュします。
